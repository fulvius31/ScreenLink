Terminal emulator and terminal view
-----------------------------------

The packages

    com.sangiorgisrl.screenlink.terminal.emulator
    com.sangiorgisrl.screenlink.terminal.view
    com.sangiorgisrl.screenlink.terminal.view.textselection

are compiled into this application as ordinary application code, under this
application's own package namespace. They are derived from the `terminal-emulator`
and `terminal-view` modules of the Termux terminal emulator
(https://github.com/termux/termux-app), tag `v0.118.0`, Copyright (c) the Termux
contributors, and are used under the Apache License, Version 2.0.

The upstream code was moved into this application's namespace and substantially
modified: it is driven by an SSH byte transport instead of a local pseudo-terminal,
it keeps its own alternate-screen transcript so touch scrolling works inside
full-screen programs, it tracks the alternate-scroll / mouse / focus modes so wheel
and touch gestures can be routed correctly, and it has been rewritten in Kotlin
(the upstream sources were Java). These modifications are covered by the same Apache
License, Version 2.0.

You can obtain a copy of the Apache License, Version 2.0 at
http://www.apache.org/licenses/LICENSE-2.0. The full licence text is also shipped
in this application as `assets/LICENSE-Apache-2.0.txt`.
